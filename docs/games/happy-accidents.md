# Happy Accidents

> "Learn from the unexpected." Every bug, playtest oddity, or weird emergent
> behaviour gets one row here. We keep, fix, or kill — never ignore.

| Date | Who | What happened | Decision | Owner |
|------|-----|---------------|----------|-------|
| YYYY-MM-DD | name | one sentence | keep / fix / kill | name |

## Rules

- **Keep** = it surprised us in a good way; promote to backlog as a feature.
- **Fix** = it broke immersion; file an issue.
- **Kill** = noted, not worth chasing.

## Template entry

> 2026-05-22 — Asha — the target spawned half off-screen and players
> *leaned* to see it; one tester laughed. **Keep** (file as "peek" mechanic
> idea). Owner: Asha.

## Weekly review (Monday, 15 min)

- Read every new row out loud.
- Vote keep/fix/kill if not already set.
- One person merges adopted "keeps" into `GDD-brief.md` open questions.
